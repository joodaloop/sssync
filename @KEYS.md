# Key Generation Functions Catalog

## Overview

Complete scan of all key generation functions in the codebase. This is a data synchronization library (sssync) with **no cryptographic key generation**. All functions are for application-level identifiers.

---

## HASH/DIGEST GENERATION (3 functions)

### `hashSchema(schema: {...}): string`

- **File:** `packages/sssync/src/schema/builder/schema-builder.ts:81-98`
- **Purpose:** Generates stable hash of database schema using FNV-1a algorithm
- **Details:** Uses BigInt arithmetic with magic numbers `0xcbf29ce484222325n` and `0x100000001b3n`. Returns hash as base-36 string. Used for schema versioning in IndexedDB database names.

### `stableStringify(value: unknown): string`

- **File:** `packages/sssync/src/schema/builder/schema-builder.ts:100-102`
- **Purpose:** Helper for deterministic JSON serialization
- **Details:** Normalizes values before stringifying for consistent hashing

### `normalizeForHash(value: unknown): unknown`

- **File:** `packages/sssync/src/schema/builder/schema-builder.ts:104-118`
- **Purpose:** Prepare objects for hashing by filtering and sorting
- **Details:** Recursively processes values, removes `hash` and `undefined` fields for deterministic output

## What's NOT in the Codebase

- ❌ Cryptographic key generation (no asymmetric/symmetric key functions)
- ❌ Random/UUID generation (no `nanoid`, `crypto.random`, `uuid` usage)
- ❌ Token generation (no JWT or session token functions)
- ❌ Encryption/signing (no crypto libraries imported)

All key generation is **deterministic and application-level**, used for database operations, caching, and query management.
